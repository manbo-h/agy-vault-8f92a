  • 第一关（商业航天极限降本的“量价剪刀差”）：传统军用遥感星是按件定制的“奢侈品”，单星相控阵 T/R 芯片价值量可达 150万—250万元 甚至更高；但万星级商业星座（对标 SpaceX 工业化流水线）的生死线是把整星造价压到千万元甚至数百万级别，占有效载荷价值大头的 T/R 芯片必然面临持续年降与多通道高集成带来的总价压缩。用 Python 做一组冷峻的敏感性测算：即便未来 GW 与 千帆 两大星座合力将年发射规模从 300颗/年 提速至 500颗/年、1,000颗/年 乃至峰值 1,500颗/年，只要单星 T/R 芯片价值量随规模化从 150万元 阶梯压缩至 120万元、80万元 与 60万元，同时公司市占率因二供/三供引入从早期先发优势的 60% 稀释至 55%、45% 与 40%，对应的星载低轨年营收分别仅为 2.70亿元、3.30亿元、3.60亿元 与 3.60亿元！也就是说，发射数量翻五倍，未必换来营收翻五倍——“年发射量暴涨”会被“单星价值量腰斩 + 份额稀释”吃掉一大半，且商业低轨批量占比越高，公司 82.29% 的超高毛利率越难守住。
  • 第二关（面向手机直连卫星的架构替代暗礁）：随着 GW 与 千帆 均把 2026—2027年 商业化重心押注在“无改造手机直连卫星（Direct-to-Cell）”，星载相控阵必须同时生成数百个动态独立波束以捕捉微弱的手机信号。纯模拟波束赋形（ABF）的波束扩展成本呈指数级飙升，行业正加速从“纯模拟”转向 “模拟子阵 + 数字波束赋形（DBF）” 的模数混合架构，长期更指向全数字阵列。在这个演变中，传统模拟 T/R 芯片的移相、衰减价值量正部分向数字域迁移，肥肉流向了高速高精度 ADC/DAC 与 DBF 芯片赛道（恰恰是同行 ST臻镭 的看家本领），倒逼铖昌科技必须用更高的高频功率效率与硅基多波束集成度来守住前端射频阵地。
  • 第三关（运力瓶颈与现金流转换）：国内大型可回收商业火箭仍处在攻关与爬坡期，海南商业发射场虽已投用，但离年发千星的常态化运力尚有距离；同时，只要终端客户仍是航天科技/科工体系与国资星座平台，验收慢、商业承兑汇票拉长账期的顽疾（2021—9M26 累计经营现金流 OCF 仍为 -0.42亿元）就会长期拖累利润含金量。

（3）竞争终局与定性：

星载芯片需要抗宇宙射线辐照、极端温差与高可靠宇航级筛选，民营企业中具备“全频段（L至W波段）+ 宇航级批量在轨飞行履历”的玩家屈指可数。体制内的电科 13所/55所（及 国博电子）体量庞大但成本机制偏重、重心在军品组件与基站；ST臻镭 强在数字全链路、ADC/DAC 与电源管理，与铖昌科技更多是“模拟前端 + 数字后端”的互补搭配。因此，铖昌科技在星载低轨赛道的先发护城河是真实存在的。最终定性：这是公司唯一真正立得住的「真实看涨期权」，赔率可观，但绝不可按 82% 毛利率和“万星无降价”做线性梦幻外推。

👴🏻 【芒格旁批】：商业航天有个经典悖论——卫星发得少，你没量；卫星发得多，整星厂为了活命一定会把你的芯片价格往死里砍。星载 T/R 芯片确实是真期权，但你得按“量增三倍、价砍一半、账期拉长”的现实剧本去算账，而不是按军品暴利去乘以一万颗卫星。

2. 曲线二：低轨地面终端 + 低空经济/反无人机·单片式硅基芯片——高毛利军工基因的“跨界排异大考”

（1）商业化刻度定位：低空是“点状小批试水”，消费级卫星终端仍卡在“成本与生态门外”。

在 2025年报 与 2026H1 中，管理层高调推出了最能激发民用想象力的王牌新品——X/Ku波段单片式硅基四通道 T/R 芯片（在硅基模拟波束赋形芯片上直接集成 PA、LNA、限幅器，采用晶圆级封装）及系列低成本前端封装产品，宣称已在 低空探测雷达、无人机防御、气象/水利雷达 实现应用及 小批量交付，同时推进卫星互联网地面终端配套。

但剥开宣传口径看硬数据：第一，公司没有单独拆分任何民用/低空/地面终端收入，全公司 94.36% 的收入仍高度锁定在仅 5家 院所级核心客户手中，这意味着纯民用市场化客户的真实收入贡献目前最多只有几百万到千万元级别，对 4亿元 营收盘子尚构不成实质业绩支撑；第二，国内低轨卫星地面相控阵终端目前整机价格仍高悬在 数千元至万元以上，距离消费级放量还差着至少一个数量级的价格鸿沟。

（2）跨越鸿沟的三道最难关卡：

  • 第一关（硅基物理天花板 vs Starlink 式极致屠价悬崖）：硅基 CMOS/SOI 工艺靠 8 寸/12 寸大晶圆把制造成本打了下来，但物理学不会撒谎——硅材料的电子迁移率与击穿电场远逊于砷化镓（GaAs）和氮化镓（GaN），在 Ku/Ka 高频段天生面临 输出功率与效率（PAE）偏低、接收噪声系数（NF）劣化、以及海量通道挤在微小芯片上导致的热流密度散热死穴。更残酷的是终端降本规律：SpaceX 联合意法半导体（ST）把 Starlink 地面终端整机造价从早期 2,500—3,000美元 硬生生压到 600美元以下（降幅超 80%），大规模量产下，一台终端用 200—400颗 硅基波束赋形芯片（BFIC），单通道成本已被压缩到 几十元人民币、单颗多通道芯片成本打到 十几甚至个位数美元！我们用 Python 反推一下商业空间：即便未来国内低轨地面终端年出货冲到 50万台、100万台 甚至 300万台，单台 T/R 芯片总 BOM 随规模化从 1,500元 压到 1,000元、600元，若铖昌科技能在红海中抢下 10%—15% 份额，年营收增量也仅在 0.75亿—1.80亿元 之间，且毛利率将大概率跌向民用射频芯片常规的 30%—45%——这对于习惯了 80% 毛利率、靠 92名 高薪研发人员每年烧掉 1.46亿元 研发费的铖昌科技而言，极易陷入“越卖民用、拉低全公司盈利质量”的基因排异！
  • 第二关（销售渠道与客户结构的彻底重构）：过去铖昌科技靠 9M26 仅 839.76万元 的销售费用（销售费用率 2.67%）就能做 3.15亿元 生意，全凭对接几家大型院所的总师团队；但低空探测雷达（各地政府空管、机场、景区、电力巡检反无人机）与消费级卫星终端（车厂、运营商、户外消费品牌）是极度碎片化的 2B/2C 市场，既要拼价格、又要拼FAE（现场应用工程师）贴身服务与海量渠道铺货，公司目前的组织架构几乎毫无民用消费级打法基因。
  • 第三关（低空基建的财政支付能力制约）：低空经济探测雷达与反无人机系统高度依赖地方政府新基建与特种安防采购预算，目前多停留在示范区试点阶段，单点项目体量小、回款依赖地方财政，短期难以汇聚成数亿元级的标准品大单。

（3）竞争终局与定性：

一旦走出宇航级抗辐照这个“特种避风港”，踏入民用硅基射频相控阵赛道，竞争格局立刻从“小圈子寡头”恶化为 “十面埋伏的绞肉机”：海外有 意法半导体、ADI、Qorvo、MACOM 坐镇；国内既有 国博电子（依托电科 55 所）、雷科防务 等老牌劲旅，更有 康希通信（旗下知融科技）等专门杀入低成本消费级射频的民用芯片厂商与大批高校孵化的硅基初创公司，甚至未来千帆/GW 终端体量起飞后，头部整机巨头完全可能效仿 SpaceX 直接找晶圆厂搞 ASIC 自研定制。最终定性：低空探测/反无人机属于利用既有技术溢出的「小众微利补丁」，而消费级卫星地面终端芯片在现有商业基因下极大概率是「平庸鸡肋甚至利润率稀释陷阱」，绝不能当成高毛利第二增长引擎来画饼。

3. 曲线三：机载相控阵通信 + 低压 GaN 第三代半导体前端——务实的横向延伸，隐藏着上游代工与流片黑洞

（1）商业化刻度定位：机载已跑通批量盈利，低压 GaN 正在跨过导入门槛。

在公司四大新方向中，机载相控阵通信 T/R 芯片 是除了星载之外兑现度最高的一条线：2025年报 与 2026H1 均明确确认，前期布局的多个机载重点项目已通过用户系统验证并进入批量供货阶段，营收实现高速增长，已成为公司主要营收部分之一。同时，在第三代半导体氮化镓方向，公司从过去用于大型地面雷达的高压 GaN 功放，进一步拓展出 低压 GaN 全集成射频前端单芯片（把 PA、LNA 和开关集成进一颗芯片），已在通信设施及相控阵系统取得关键进展。

更值得买方细品的一个隐蔽加分项藏在资产负债表里：铖昌科技账面趴着 9,799.81万元 的 其他权益工具投资（初始投资成本 5,500.00万元，累计公允价值升值 4,299.81万元），标的正是 浙江集迈科微电子有限公司（铖昌科技持股 5.00%，控股股东和而泰另持股 7.01%）。集迈科坐拥 4 英寸 GaN、6 英寸 GaAs 与 8 英寸硅基三维异构微系统 代工产线，2025年 铖昌科技向其采购晶圆及委托加工金额达 1,026.37万元（同比大增 +64.10%，位列第四大供应商，占比 7.03%）。这种以小额参股绑定本土特色化合物工艺线的做法，比自己砸几十亿重资产建 Fab 厂聪明得多，也支撑了公司年报中强调的“设计-工艺-封装三位一体”联合开发能力。

（3）竞争终局与定性：

背靠民营灵活机制、上千款货架型谱以及参股 集迈科 的工艺协同，铖昌科技在机载通信与低压 GaN 细分领域足以在国家队巨头身旁稳健切下份额，但业务本质仍是传统特种相控阵主业的“横向平移”。最终定性：已成功落地的「稳健次级期权」，能帮公司平滑单一下游波动、增厚业绩底盘，但不具备打破特种行业天花板的颠覆力。

👴🏻 【芒格旁批】：把铖昌科技和雷电微力、国博电子摆在同一张表里，你就会立刻醒悟——这门生意在顺风时像印钞机，在客户推迟提货或集采降价时就像断了线的风筝。参股集迈科锁住国产代工是一步好棋，但它改变不了“研发越做越碎、账期越拉越长”的行业地心引力。

4. 曲线四：5G 毫米波基站 + 太赫兹前沿预研——彻底证伪的“历史遗留故事”

（1）商业化刻度定位：官方财报已用脚投票，实质归零。

很多投资者还在翻看 2022年 上市时的招股书和老旧研报，幻想铖昌科技能借“华为/中兴 5G 毫米波基站国产替代”打开百亿民用市场，甚至畅想 6G 太赫兹爆发。但我们用脚本全量穿透公司最新的 2025年年度报告（全文 201页），得到了最冷酷的法医级实证：整份 2025 年报里，5G、太赫兹、手机直连 三个词的出现次数全部是 0次！ 在 2026年半年度报告（154页）中，也仅在行业宏观概述中顺带提了一句 5G-A 与 6G 政策套话，在《主要研发项目》清单里完全找不到 5G 毫米波或太赫兹项目的踪影。管理层自己都已经悄悄把这些故事从年报主战场里删掉了，市场如果还拿它讲故事，纯属刻舟求剑。

（2）跨越鸿沟的三道最难关卡：

  • 第一关（毫米波不可违逆的物理学死穴）：26GHz/28GHz 毫米波波长极短、绕射与穿墙能力极差，遇建筑、树叶乃至雨雪即剧烈衰减，单个宏站覆盖半径通常不到 200米。要实现连续广覆盖，基站密度必须是 3.5GHz 中频的数倍至近十倍，网络建设与耗电运维成本是个无底洞；
