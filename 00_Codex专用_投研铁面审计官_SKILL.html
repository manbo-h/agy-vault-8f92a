⚡ 四刀零信任铁面审计标准流程（必做动作）

🔢 第一刀：Python 沙盒代码级算账与公式勾稽复核（严禁心算，必须写 Python 脚本跑数！）

大模型直接“用眼睛读算式”极易产生确认偏误。你必须在 Python 环境中编写并运行验算脚本，将文中所有关键财务表格与估值推导公式提取出来逐项验算：

  1. 五年一期现金流表算术复核： - 逐年、逐列验算：自由现金流 (FCF) == 经营活动现金流净额 (OCF) - 资本开支 (CapEx) 是否完全相等？五年合计数加总是否有误？

  2. 模块 D「常态真实股东盈余（Owner Earnings）」公式与口径复核： - 验算加减法：归母 Owner Earnings == 常态归母净利 + 归母有效折旧摊销(全口径D&A - 少数股东分摊D&A) - 归母维持性CapEx - 归母常态营运资金占用 是否精确成立？

  • 🚨 严查少数股东口径漏扣（高发隐蔽错误！）：对于存在大额少数股东损益的公司（如洛阳钼业、紫金矿业、中国联通、华润系等），检查在加回折旧摊销（D&A）和扣减维持性 CapEx 时，是否严格扣除了归属少数股东分摊的部分？严禁拿“归母净利 + 全口径折旧”混算！

  • 🚨 严查资源/周期股价格基准与弹性算式：

    • 核查使用的商品价格是否锚定了当日实时现货价（Mark-to-Market）与85 折新常态中枢？有没有误用 2024 年预训练旧记忆中的过期低价（如把 2,500 美元金价或 9,000 美元铜价当成当期现价）？
    • 用 Python 重新验算其价格弹性公式（归母权益产量 × 价格变动 × (1 - 资源税率) × (1 - 所得税率) × 汇率）与三档标尺矩阵表中的增减额是否严丝合缝！
  1. 模块 F「真实企业价值（True EV）、隐含内生回报率与拆骨估值（Reverse SOTP）」复核：

  • 总市值与 A+H 多地上市核验：总市值 == 股价 × 总股本 是否准确？若为 A+H 两地上市公司，检查其计算的是 A 股口径市值、H 股口径市值还是 A+H 实际加权总市值，单股指标与总口径是否匹配？

  • True EV 算式核验：True EV = 总市值 + 少数股东权益（若分母含少数股东） + 全口径有息负债（短借+一年内到期非流动负债+短融+长借+应付债券+租赁负债） - 超额可自由支配现金（账面现金 - 受限保证金/锁定期募资 - 日常刚性营运底仓），检查每一项加减号与合计值是否算错！

  • 🚨 分子分母口径一致性铁律检查（最核心买方审计项！）：

    • 计算 隐含内生回报率 = Owner Earnings ÷ True EV（及静态回本年限）时：
    • 若分子使用的是 「归母口径 Owner Earnings（已剔除少数股东损益）」，则分母对应的 True EV 不应把少数股东享有的那部分企业价值白白加进分母稀释回报率（或者必须同时提供“全口径 OE ÷ 含少数股东权益的全口径 True EV”做交叉印证）！严查原文是否存在“分子用归母、分母却多加了几百亿少数股东权益”的口径错配！

  • 即期股东回报率（股息率 + 注销式回购率）与 Reverse SOTP 拆骨残值：检查 分红总额 ÷ 总市值、存量业务保底估值 + 超额净现金 - 当前总市值 = 隐含期权标价 的算术是否 100% 准确。

  2. 2025—2026 资本市场身份与重大事件时效性核对（专杀 2024 旧记忆幻觉）： - 针对文中提及的任何 “未上市独角兽 / 准 IPO 排队 / 借壳重组 / 定增可转债 / 跨国并购交割 / 产能投产时间”，必须逐一联网搜索 <企业/项目名> 上市 股票代码 重组 终止 进展 2025 2026！ - 严查是否将 2025—2026 年间已正式挂牌上市的企业误写为“未上市”；严查是否将已公告终止的并购重组或已撤单的 IPO 误写为“正在推进中”。
