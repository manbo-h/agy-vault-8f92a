1.3 转固折旧增量与盈亏平衡压测：国内低门槛 vs 沙特高门槛

依据 2026半年报 第 82 页及第 109—110 页固定资产附注，瑞丰新材采用年限平均法计提折旧，房屋及建筑物折旧年限 10—30年（年折旧率 3.17%—9.70%），机器设备折旧年限 5—15年（年折旧率 6.33%—19.40%）。经 Python 对 2026H1 实际计提折旧（0.5642亿元，现金流补充表口径 0.5749亿元）与期初期末固定资产原值均值（15.36亿元）反推：公司实际综合年化折旧率为 7.34%（其中房屋建筑物实际年化折旧率 4.51%，机器设备实际年化折旧率 8.81%）。按典型化工装置 35%厂房 + 65%机器设备 资产结构加权，未来新建生产项目转固后的稳态综合折旧率锁死为 7.30%。

  • 情景二：沙特延布合资基地一期转固（1.27亿美元 折约 9.14亿元）

  • 假设未来 3—4年 内上述 23.14亿元（含产业研究院剩余投资、新乡 46万吨 及 15万吨 尾款、锦州收尾及沙特一期）全部完工转固，公司年度固定资产折旧将从 2025年 的 0.98亿元（2026H1 年化 1.13亿元）跃升至约 2.67—2.82亿元，净增折旧 1.69亿元/年（全口径固定成本增量约 2.54亿元/年）。

2.1 存量表观稼动率仅 56.92%，折射的是“总量宽松、结构紧缺”

根据 2025年报 第 18—20 页原数，截至 2025年末 公司润滑油添加剂单剂设计产能已达到 31.50万吨，但全年实际生产量为 179,305.89吨（同比 +16.17%），销售量为 180,296.36吨（同比 +13.47%），期末库存 12,091.40吨（同比 -7.57%）。用产量除以期末设计产能直接硬算，公司 2025年 表观产能利用率仅为 56.92%！

从绝对数字看，存量产线似乎还有超过四成的富余空间，绝非“产能爆满、一吨难求”的全面瓶颈状态。这也彻底解释了为何管理层在 2025年8月22日 果断拍板——将 新乡15万吨 和 新乡46万吨 达到预计可使用状态的日期双双延后三年至 2028年12月31日。官方公告措辞相当坦诚：“为了更好地协调平衡市场需求、客户拓展与产能规划，提高建成项目的产能利用率”。

但深入精细化工生产排产逻辑，不能简单将 56.92% 等同于全线过剩，其背后藏着两层结构性真相：

  • 精细化工的“多品种柔性切换损耗”：润滑油添加剂涵盖清净剂（高/中/低碱值磺酸盐、硫化烷基酚钙、水杨酸盐）、无灰分散剂、ZDDP、高温抗氧剂、黏指剂等数十个大类、数百个定制牌号。不同牌号共用或切换反应釜涉及清釜、置换与批次质检，行业常规满产有效稼动率上限本身就在 75%—85% 之间，并非大宗石化连续装置的 95%—100%。
  • 老旧通货过剩 vs 高端单剂/复合剂缺口：当前国内润滑油添加剂市场（年需求约 100万吨，全球约 500万吨）已步入阶段性结构性过剩——常规低端单剂与低级别（如 API CD/CF/SG）复合剂供给严重饱和，价格战白热化；但真正能替代国际四大寡头（路博润、润英联、雪佛龙奥伦耐、雅富顿，合计垄断全球约 85% 份额）的高碱值硫化烷基酚钙、低灰分清净分散剂、船用汽缸油复合剂及适配 API SP/SQ、ILSAC GF-7、CK-4 与中国首个自主 D1 柴油机油标准的高端产线，仍存在明显的质量一致性与产能瓶颈。

  • 1. 绿地海外建厂的“工期滞后 + 造价超支”魔咒：沙特延布虽为成熟石化工业城，但当地极度缺乏成建制的精细化工熟练安装工人与本土化设备供应链，加之夏季酷热极端施工环境与严苛的沙特皇家委员会（RCJY）工程标准，中资化工企业在沙特建厂普遍面临建设周期比国内长 1.5—2倍、实际造价较可研预算超支 15%—30% 的历史规律。一期 1.27亿美元（约 9.14亿元）资金中，首期股东现金仅出资 2,500万美元，剩余超 1亿美元 缺口高度依赖股东后续增资或当地项目银团贷款，融资成本与汇率波动将直接吞噬初期回报。
